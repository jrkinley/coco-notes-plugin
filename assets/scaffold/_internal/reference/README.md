# Reference material

Third-party reading kept for reference: papers, whitepapers, PDFs, articles worth returning to.

**Contents are deliberately not tracked in git.** These are other people's documents, often large, and
usually still available from source. This README is the only tracked file in the folder.

Give files a name that says what they are, not whatever they were called on download. If the source is
not obvious from the filename, record it in a line below.

Cite reference material by reading it, not by paraphrasing from memory.

This is for things other people wrote. Your own reusable assets go in `artefacts/`.
