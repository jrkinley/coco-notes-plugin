# Reporting

Recurring reporting cycles: quarterly business reviews, and anything else you have to produce on a
schedule and present.

```
reporting/
  qbr/
    FY27Q1/
      index.html     The deck
      assets/        Deck images
      notes/         Prep notes and the data behind the numbers
```

A cycle owns everything about it. The deck, the prep, and the supporting data sit together, so when
someone asks where a number came from a quarter later, the answer is in the same folder as the slide
that claimed it.

Start a new folder each cycle rather than editing the last one. Previous quarters are the record of
what you actually said at the time, which is worth more than a tidy single copy.

This is the one place a deck lives outside `_internal/slides/`. A deck belonging to a reporting cycle
belongs with that cycle.
